# Vinyl | Restaurant & Bakery

A responsive landing page for a fictional coastal-modern restaurant and bakery.

## Project Brief

Vinyl presents a tasteful restaurant brand with a warm coastal aesthetic. The landing page showcases the business through a multi-section layout, clear service descriptions, a team section, and a contact form with validation.

## Features

- Responsive, mobile-first design
- Semantic HTML5 with accessible structure
- Navigation menu with section anchors
- Hero section with value proposition
- Services/products section with descriptive cards
- Contact form with required fields and browser validation
- Footer with social links and copyright
- Embedded media placeholder video
- SEO-friendly meta tags and headings

## Technologies

- HTML5
- CSS3

## Setup Instructions

1. Open `index.html` in a browser.
2. For best results, use Chrome, Firefox, or Safari.
3. No build tools are required.

## Deployment

This project can be deployed via GitHub Pages by hosting the repository's `main` branch or `docs/` folder.

## Business Rationale

Vinyl Bakery is designed to appeal to guests seeking refined coastal dining and approachable event hospitality. The modern layout communicates quality while the content highlights curated menu experiences and personalized service.
